🧑‍💻 My Portfolio – Frontend Assignment Project

This is a simple and responsive **personal portfolio website** built using **React**, **Tailwind CSS**, **HTML**, and **JavaScript**. It showcases my profile, resume download option, contact section, hobbies, and an about me section.

🚀 Technologies Used

- ⚛️ **React JS**
- 🎨 **Tailwind CSS**
- 🧱 **HTML5**
- 🧠 **JavaScript (ES6+)**
